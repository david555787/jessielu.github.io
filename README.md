# Jessie Lu portfolio — independent rebuild

This version is a clean static implementation made from new source files. It preserves the original portfolio's content, routes, dark/light themes, responsive layout, and interactive visual language without using the original React component structure. The homepage particle-text animation is adapted from the official React Bits implementation; see `THIRD_PARTY_NOTICES.md`.

## Files

- `index.html` — semantic content for all five views
- `styles.css` — responsive layout and visual styling
- `app.js` — hash navigation, theme controls, canvas particles, spotlight cards, magnetic buttons, heading animation, and email copy
- `assets/jessie-lu.jpg` — portrait used on the About view

Open `index.html` in a browser, or serve the repository root with any static web server.
