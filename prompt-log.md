## Project Goal and AI Use

For this assignment, I used AI-assisted “vibe coding” to create a personal portfolio website. The goal was to introduce myself, share my academic and career interests, and provide a place to display my projects, experience, and contact information.

ChatGPT was part of my project workflow, as described above. The current website footer also credits Codex. Without the original conversation history, I cannot reliably attribute individual parts of the code to particular prompts or distinguish every contribution made by each tool.

## Website Content and Organization

The website is organized as a single page with navigation links to five main sections:

- About: My background as a Carnegie Mellon Information Systems student, a personal photo, and a list of technical skills.
- Projects: The personal portfolio itself, along with an Algorithm Notebook marked as planned and a Market Simulator marked as an idea. These future projects are not presented as completed work.
- Experience: A description of participation in Jane Street WISE.
- Interests: Ultimate frisbee, poker, cello, fashion, and art.
- Contact: Links to email, GitHub, and LinkedIn.

The introduction highlights my interests in software engineering, quantitative finance, and trading.

## Implementation Details

The current website uses HTML and references separate CSS and JavaScript files. The HTML defines the page structure, text, images, navigation, and links.

It also includes controls for a mobile navigation menu and theme switching. Accessibility-related markup includes a “Skip to content” link, descriptive alternative text for the portrait, and labels for navigation and buttons. These details describe what is present in the HTML; they are not a claim that every feature has been fully tested.
