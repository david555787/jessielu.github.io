# Jessie Lu — Personal Portfolio

A clean, interactive portfolio website designed around a **60% personality / 40% recruiter** balance.

## Concept

The visual direction combines:

- Minimal, Apple-like typography and whitespace
- Futuristic interface details
- A restrained lime accent
- Subtle motion rather than distracting animation
- Personal interests presented as part of the identity
- Recruiter-friendly sections for education, experience, skills, and contact

The goal is to communicate:

> Curious. Technical. Analytical. Human.

## Files

```text
portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`
The complete semantic structure and content of the portfolio.

### `style.css`
All visual styling, responsive layouts, animations, typography, and effects.

### `script.js`
Small interactive touches:
- Cursor glow
- Scroll reveal animations
- Interactive interest cloud
- Smooth navigation
- Copy-name button

## Run locally

No build system is required.

### Option 1 — open directly

Double-click `index.html`.

### Option 2 — use a local server

If Python is installed:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload the four files.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select your main branch and `/root`.
6. Save.

Your portfolio will then be available through GitHub Pages.

## Recommended next upgrades

The current version is intentionally honest about having no major projects yet. As projects and experience accumulate, add:

- A featured projects section with GitHub links
- Resume PDF
- More detailed Jane Street / WISE experience
- Coursework
- Awards / competitions
- Technical writing or notes
- A real email contact link
- Project demos
- A custom domain

## Content to personalize

Before publishing, consider adding:

- Your CMU email
- Your resume
- GitHub profile
- Actual project links
- Exact dates / location for WISE if desired
- Any clubs, competitions, or leadership
- Quantitative achievements where available

## Design principle

Don't try to look like a senior engineer when you're a first-year student.

The strongest version of this site should show **trajectory**: someone early in their career who is unusually curious, technically serious, and actively building.
